# Audio Anomaly project instructions

Read `README.md`, `PRD.md`, and `PLAN.md` before project work. Use `docs/PROJECT_REVIEW.md` for the reviewed implementation baseline.

Preserve the distinction between implemented behavior, proposed requirements, and adopted decisions.

The current phase is discovery. Follow the current user request for task scope. Discovery records do not authorize future implementation.

Preserve `sample graph.txt` as exploratory reference material. Do not treat it as a final-build preset.

The `agent-project-management/` directory contains an unadopted reference framework. Its starter instructions apply to that starter subtree.

Keep management records small. Update the existing records before adding overlapping documents.

Report source inspection separately from runtime verification. Audio changes require meaningful playback and export checks appropriate to the change.
